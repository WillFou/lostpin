# Recette V6.2.2

## 1. start.bat

1. Sans `config/config.js` : LostPin demande une cle.
2. Avec le placeholder `PASTE_YOUR_GOOGLE_MAPS_KEY_HERE` dans le fichier : LostPin demande une cle.
3. Avec n'importe quelle autre valeur dans `config/config.js` : LostPin demarre sans verifier le format de la valeur.

## 2. Mini-carte

- Carte reduite : la transparence reste visible meme avec la souris au-dessus.
- Le survol ne change jamais sa taille.
- Bouton/M : carte agrandie et opaque.
- Echap : retour a la taille reduite et translucide.
- Resultat : carte opaque.

## 3. Workflow test -> depot

Depuis un dossier de test ou `config/config.js` contient une cle locale :

```powershell
.\sync-to-repo.bat
```

Par defaut la cible est `D:\Web\LostPin`. On peut fournir une autre cible en premier argument.

Verifier ensuite dans le depot :

```powershell
git ls-files -- config.js config/config.js
git check-ignore -v --no-index -- config/config.js
git config --get core.hooksPath
git status
```

Attendu : `git ls-files` ne retourne aucune configuration locale, la regle d'ignore est affichee et `core.hooksPath` vaut `.githooks`.

## 4. Garde-fous

- `pre-commit` doit bloquer une configuration forcee dans l'index ou une cle Google dans un fichier texte staged.
- `pre-push` doit recontroler le contenu de `HEAD` avant envoi.
- `publish-release.bat 6.2.1` doit etre refuse car `version.json` contient 6.2.2.
- `publish-release.bat 6.2.2` ne doit etre lance qu'apres commit/push propres.

## 5. Non couvert

- Les trois modes d'affichage de carte OpenGuessr ne sont volontairement pas modifies dans cette release : de nouvelles captures sont attendues.
- Tester Google Maps reel et PeerJS entre plusieurs PC comme pour V6.2.1.
