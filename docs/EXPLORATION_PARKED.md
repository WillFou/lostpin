# Exploration - mode mis de côté en V6.0.12

Le mode Exploration a été retiré de l'interface publique car son game design n'est pas assez engageant dans son état actuel.

Le moteur et les données historiques restent volontairement présents dans le code afin de pouvoir repartir du prototype existant lors d'une future refonte du gameplay.

Décision V6.0.12 : ne pas réexposer Exploration avant d'avoir redéfini une boucle de jeu plus intéressante.
