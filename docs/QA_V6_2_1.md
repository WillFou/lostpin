# Recette V6.2.1

## Exécuté ici

- 118/118 assertions Chromium sur le HTML/CSS et les contrôleurs de production, avec Google Maps/Street View simulés et réseau désactivé.
- 12/12 tests Node de géométrie HUD (normalisation, bornes, antiméridien, interpolation, horloge).
- Syntaxe JavaScript, références DOM statiques, ressources locales et contrôle de l'archive source.
- Git dans des dépôts temporaires : ancien/nouveau chemin config ignoré, exemple suivi, benchmark exclu et retrait du suivi sans suppression locale.

Les 118 assertions couvrent Off/60/120/180, préférence persistante, timeouts avec/sans point, soumission double, plafonnement du temps, sons, indépendance Blitz/Challenge/multi, No Move/NMPZ, opacité et expansion volontaire, commandes bas-gauche, boussole, fin de 5 manches, somme des scores, sélection d'une manche, vue globale et replay.

Tailles testées : 1366x768, 1920x1080, 2560x1600, 3200x2000, 3840x2160, 1024x768, 768x1024, 390x844. Le rapport JSON local est produit sous `dev/qa/artifacts/v621/` (ignoré et non livré).

## Limites explicites

- Aucune requête Google réelle ni facturation API pendant ces tests.
- Aucun test PeerJS entre PC réels. Le chrono multi reste propriété du contrôleur multi ; le test vérifie seulement qu'il ne reçoit pas le timer solo.
- Les polices distantes ne sont pas chargées dans les captures hors ligne.
- Pas d'environnement Windows/PowerShell/.NET : les scripts de publication et le workflow doivent faire l'objet d'un premier passage réel.
- Les résultats simulés n'équivalent pas à une validation du produit par l'utilisateur.

## Tests rapides recommandés sur l'installation réelle

1. Sécurité : clé remplacée/restrictive, config retirée du suivi. `git ls-files -- config.js config/config.js` doit être vide. Tester Test-Release sans faire de publication.
2. Classique 60 s : laisser expirer sans point, puis avec un point ; vérifier 0 dans le premier cas et validation dans le second, les sons et le verrouillage de l'image.
3. Classique Off : absence de décompte. Passer à Blitz/Challenge/multi puis revenir : aucun chrono hérité par erreur.
4. Carte : observer la transparence hors survol ; cliquer un point sans agrandir ; agrandir avec le bouton et M, réduire avec Échap. Vérifier le retour au départ en bas à gauche.
5. Terminer cinq manches, redimensionner le récapitulatif, cliquer une manche puis Toutes les manches, rejouer. Vérifier que les tuiles Google se redessinent correctement.
6. Publication Windows : garde-fou refuse une mauvaise version ; publication 6.2.1 seulement après commit/push propres. Le ZIP de Release ne doit contenir aucun config.js.

## Relancer les tests hors ligne

```text
node --test dev/qa/hud-math.test.js
python -m pip install playwright beautifulsoup4
python -m playwright install chromium
python dev/qa/v621-browser.py
python dev/qa/v621-static.py
```

`LOSTPIN_CHROMIUM` peut indiquer un chemin vers Chromium. Les scripts utilisent seulement une fixture HTML en mémoire et ne nécessitent aucune clé. Le script statique requiert Git et Node sur PATH.
