Le script teste la sortie compilee puis un dossier de publication neuf, en lancant un vrai serveur

restent a tester. Les correctifs de hooks/synchronisation sont verifies dans les sources, mais
les scripts PowerShell/BAT n'ont pas ete executes ici.
